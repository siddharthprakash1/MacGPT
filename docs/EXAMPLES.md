# Usage Examples & Common Workflows

Real-world examples of what you can do with your macOS AI Commander.

## 🎯 Quick Start Examples

### Basic System Control

```
"Send a notification saying Meeting starts in 5 minutes"
→ Displays macOS notification

"What's my battery level?"
→ Returns battery percentage and charging status

"Set volume to 50%"
→ Adjusts system volume

"Set brightness to 70%"
→ Adjusts screen brightness

"Lock my screen"
→ Locks Mac immediately

"Toggle dark mode"
→ Switches between light and dark mode
```

### Window Management

```
"Snap Chrome to the left and Safari to the right"
→ Arranges windows side-by-side

"Maximize Visual Studio Code"
→ Maximizes VS Code window

"Center the current window"
→ Centers frontmost window on screen

"Show me all open windows"
→ Lists all windows with positions

"Move Spotify to the top-left corner"
→ Positions window at specific location

"Resize Chrome to 800x600"
→ Sets specific window dimensions
```

### File Operations

```
"List all files in my Downloads folder"
→ Shows directory contents

"Compress all PDFs in Desktop into archive.zip"
→ Creates ZIP file of PDFs

"Find all Python files in my Documents"
→ Searches for *.py files

"Move all PNG images from Downloads to Pictures"
→ Batch moves files

"Rename report.pdf to final-report.pdf"
→ Renames file

"Get info about that video file in Downloads"
→ Shows file size, type, modified date
```

## 💡 Pro Tips

### Chaining Commands

Instead of multiple requests:
```
❌ "Open Chrome"
❌ "Open Safari"  
❌ "Snap them side by side"
```

Do this:
```
✅ "Open Chrome and Safari and snap them side by side"
```

### Being Specific

Instead of:
```
❌ "Make it bigger"
```

Do this:
```
✅ "Maximize the Chrome window"
```

### Natural Language

The AI understands natural speech:
```
✅ "Hey, can you snap that window to the left?"
✅ "Maximize this"
✅ "Open my browser and email"
✅ "What's my battery at?"
```

## 🎓 Learning Resources

### Command Patterns

**Opening Apps:**
- "Open [app]"
- "Launch [app1], [app2], and [app3]"
- "Start [app]"

**Window Management:**
- "Snap [app] to [left|right|top|bottom]"
- "Maximize [app]"
- "Resize [app] to [width]x[height]"
- "Center [app]"

**File Operations:**
- "List files in [folder]"
- "Compress [files] into [name].zip"
- "Move [files] to [destination]"
- "Find [pattern] in [folder]"

**System Control:**
- "Set [volume|brightness] to [value]%"
- "Enable/Disable/Toggle [feature]"
- "Check [system aspect]"

**Web Operations:**
- "Scrape [url]"
- "Download [url]"
- "Check if [url] is up"
- "Test internet speed"
