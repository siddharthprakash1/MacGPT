1. PROJECT OVERVIEW
================================================================================

MacGPT is an AI-powered macOS automation system that allows users to control 
their entire Mac through natural language commands. It uses Ollama for local 
LLM inference, providing complete privacy without cloud dependencies.

KEY STATS:
- 228 total automation tools
- 17 tool categories
- 100% local AI (no cloud)
- Modern dark-mode Web UI
- Voice control support (CLI mode)
- One-line installation

GITHUB: https://github.com/siddharthprakash1/MacGPT

2. TECH STACK & ARCHITECTURE
================================================================================

BACKEND:
- Python 3.9+
- Flask (Web Framework)
- Requests (HTTP client with connection pooling)

AI/ML:
- Ollama (Local LLM server)
- Models: mistral, llama3.1, gemma2:27b, gpt-oss:20b
- Vosk (Offline speech recognition)

macOS INTEGRATION:
- AppleScript (osascript)
- PyObjC (Python-Objective-C bridge)
- subprocess (shell commands)
- mdfind/mdls (Spotlight search)

FRONTEND:
- HTML5, CSS3, Vanilla JS
- Inter font family
- Dark theme only (ChatGPT/Claude inspired)

PROTOCOL:
- Model Context Protocol (MCP) for tool execution

5. KEY FEATURES & IMPLEMENTATIONS
================================================================================

A. SPOTLIGHT INTEGRATION (spotlight_tools.py):
   - Uses mdfind/mdls for native Spotlight queries
   - Filters out system/cache files by default
   - Scans all app locations (including Homebrew Caskroom)
   - Natural language query parsing
   - Full-text content search inside files
   
   Key exclusion patterns:
   - /Library/, /Caches/, /.Trash/, /node_modules/, /.git/
   - /Application Support/, /Containers/, /.cursor/
   - SQLite journals, log files

B. SPOTIFY CONTROL (advanced_tools.py):
   - Uses AppleScript to control Spotify desktop app
   - NOT web player - direct app control
   - Mood/genre-based playlists via Spotify search URLs
   - Volume control, shuffle, repeat modes
   - Track info and player status
   
   Example AppleScript pattern:
   ```applescript
   tell application "Spotify"
       play
       set sound volume to 50
       next track
   end tell
   ```

C. BROWSER AUTOMATION (advanced_tools.py):
   - Uses AppleScript with JavaScript execution
   - Supports Chrome, Brave, Safari, Arc
   - Tab management via AppleScript + keyboard shortcuts
   - URL/title extraction
   - Search integration (multiple engines)
   
   Browser detection priority:
   1. User-specified browser
   2. Chrome (default)
   3. Safari (fallback)

D. WEB UI (ui/templates/index.html):
   - Dark-mode only design
   - Inter font family
   - ChatGPT/Claude-inspired minimal aesthetic
   - CSS variables for theming
   - Auto-resizing textarea
   - Collapsible tool execution cards
   - Subtle fade-in animations
   - No glassmorphism/particles/gradients

E. ONE-LINE INSTALLER (install.sh):
   ```bash
   curl -fsSL https://raw.githubusercontent.com/siddharthprakash1/MacGPT/main/install.sh | bash
   ```
   Creates:
   - ~/.macgpt directory
   - Virtual environment
   - /usr/local/bin/macgpt command
