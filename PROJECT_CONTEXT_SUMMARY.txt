# 📋 COMPLETE PROJECT CONTEXT SUMMARY

## 🎯 PROJECT OVERVIEW

**Name**: MacGPT  
**GitHub**: https://github.com/siddharthprakash1/MacGPT  
**Purpose**: A powerful macOS automation system that acts as a "better Siri" - an AI assistant that actually executes commands (like Google Gemini on Android) instead of just providing information.

**Tech Stack**:
- Python 3.14
- Ollama (Local LLM) - currently using `gpt-oss:20b` model
- Flask web UI (HTTPS on port 7889)
- macOS system-level automation via AppleScript, subprocess, native utilities
- 189 advanced tools across 20+ categories
- Voice control in CLI (Vosk for speech-to-text, macOS `say` for TTS)

**License**: MIT

## 🔧 TECHNICAL ARCHITECTURE

### **Core Components**

1. **`core/mcp_server.py`**
   - Main MCP server
   - Tool registration and management
   - Request/response handling

2. **`core/ollama_client.py`**
   - Ollama LLM integration
   - Function calling orchestration
   - Voice control (CLI only):
     - `voice on/off` - Toggle voice output
     - `listen` - Voice input via Vosk
     - Text-to-speech via macOS `say`
   - Interactive CLI loop
   - Streaming responses

3. **`tools/advanced_tool_registry.py`**
   - Central registry for all 189 tools
   - JSON schema definitions
   - Function mappings

### **Execution Flow**

```
User Input (CLI/Web) 
  → Ollama LLM (gpt-oss:20b)
  → Function Selection
  → Tool Execution (AppleScript/subprocess/Python)
  → Response Formatting
  → Output (CLI/Web UI)
```

### **macOS Integration Methods**

1. **AppleScript** (`osascript`) - App control, window management, UI automation
2. **Subprocess** - Shell commands (`open`, `screencapture`, `mdfind`, `networksetup`)
3. **Native utilities** - `cliclick` for mouse, `say` for TTS
4. **Direct file I/O** - Python file operations
5. **Third-party CLIs** - Homebrew, npm, pip, git, docker

## 🔑 KEY IMPROVEMENTS MADE

### **1. Resolution-Independent Window Management**
- **Problem**: Hardcoded pixel values failed on different screens
- **Solution**: All window operations use percentages of detected screen dimensions
- **Multi-monitor**: Supports multiple displays with `display` parameter
- **Works on**: Any MacBook, external monitor, ultrawide, 4K

### **2. Resolution-Independent Mouse Control**
- **Problem**: "Move mouse to center" used hardcoded (1824, 559)
- **Solution**: Dynamic `get_screen_size()` calculates center for ANY resolution
- **Named positions**: `center`, `top-left`, `top-right`, `bottom-left`, `bottom-right`, `top-center`, `bottom-center`, `left-center`, `right-center`
- **Latest commit**: `59527b5` - "feat: dynamic mouse positioning - resolution-independent"

### **3. Web Scraping Enhancements**
- **Problem**: 403 Forbidden errors on websites
- **Solution**: Realistic browser headers (User-Agent, Accept, etc.)
- **Improved extraction**: Removes scripts/styles, prioritizes `<main>`/`<article>`

### **4. Speed Test Accuracy**
- **Problem**: Too fast, unreliable results
- **Solution**: 50MB download test, 20+ second duration
- **Added**: Upload speed test

### **5. Spotify Integration**
- **Problem**: Generic "play music" didn't work for Spotify
- **Solution**: New `play_spotify_track` tool with search functionality

### **6. Side-by-Side Windows**
- **Problem**: Second app covered first app when snapping
- **Solution**: New `snap_side_by_side` tool that arranges both apps simultaneously without activating them

### **7. Network Info Compatibility**
- **Problem**: Old `airport` utility path no longer exists
- **Solution**: Using `networksetup -getairportnetwork` and `ipconfig getifaddr`

### **8. Music Control AppleScript**
- **Problem**: `next`/`previous` are reserved keywords
- **Solution**: Changed to `next track`/`previous track`

## 🚨 IMPORTANT KNOWN ISSUES & SOLUTIONS

### **1. Accessibility Permissions Required**

**Error**: `System Events got an error: osascript is not allowed assistive access. (-1719)`

**Solution**:
```
1. System Settings → Privacy & Security
2. Accessibility → Click lock icon
3. Add Terminal.app or Python executable
4. Check the box to enable
5. Restart terminal/script
```

### **2. Dependencies Installation**

**Required packages**:
```bash
brew install portaudio pkgconf ffmpeg cliclick
pip install -r requirements.txt
```

**Python 3.14 compatibility**:
- ✅ Vosk (speech recognition)
- ❌ openai-whisper (requires <3.14)
- ❌ faster-whisper (build issues)

### **3. GPG Signing in Sandbox**

**Issue**: Git commits may fail with GPG signing in sandbox
**Solution**: Use `--no-gpg-sign` flag or configure `git config commit.gpgsign false`
